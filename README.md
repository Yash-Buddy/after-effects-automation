# After Effects Scripts

A collection of Adobe After Effects scripts I use to automate
animation and repetitive design workflows.

## Scripts

### Auto Layout

Automatically arranges selected layers with consistent spacing.

**File:**

`scripts/auto-layout.jsx`

## Installation

1. Download the `.jsx` file.
2. Open Adobe After Effects.
3. Go to:

`File → Scripts → Run Script File...`

4. Select the `.jsx` file.

## Requirements

Adobe After Effects CC or later.
