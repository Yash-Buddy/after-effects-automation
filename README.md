# After Effects Scripts

A collection of Adobe After Effects scripts I use to automate
animation and repetitive design workflows.

## Scripts

Note

These scripts are created to perform specific tasks and automate parts of my After Effects workflow.

They may not work correctly for every project or setup. Please review the script and understand what it does before using it in your own project.

If you’re unsure about how a script works or want to use it for a different workflow, feel free to ping me before using it.

This repository contains my personal experiments and explorations with After Effects automation and scripting.

I’m uploading these scripts mainly as a record of my experiments and learning process. Some scripts are created for specific tasks and may not be production-ready or broadly reusable.

If you plan to use or adapt any of these scripts, please review them first and feel free to reach out before using them.

### Auto Layout

Automatically arranges selected layers with consistent spacing.

**File:**

`scripts/auto-layout.jsx`

## Installation

1. Download the `.jsx` file.
2. Open Adobe After Effects.
3. Go to:

`File → Scripts → Run Script File...`

4. Select the `.jsx` file.

## Requirements

Adobe After Effects CC or later.
